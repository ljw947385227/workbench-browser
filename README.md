# EnWork 工作台浏览器助手

独立 EnWork Harness 插件，当前版本 **0.7.0**。自动关联当前聊天右侧的工作台网页，直接发送要求即可让 Agent 读取页面、点击新增、找到表单并填写。没有常驻助手窗口，无需手动关联或发送页面引用。安装包已正式改名为 `@enwork/workbench-browser`。升级前卸载旧包 `@enwork/form-assistant`，不要同时启用两个包。

支持两类目标：现有同源 iframe 由本插件的 `workbench_browser` 驱动；独立浏览器继续由已安装的 wqty123/dsh-browser 的 `dsh_browser_*` 工具驱动。Agent 根据目标选择工具。本插件不安装 dsh-browser，不会把工作台 URL 重新打开到另一个窗口冒充操作原工作台。

## 安装体验

需要 EnWork Harness >=0.2.2-rc.1 <0.3.0、Node >=24.9。

1. 在实际使用的 EnWork 应用进入“插件 → 安装第三方插件”，输入本仓库 `dist/enwork-workbench-browser-0.7.0.tgz` 的绝对路径，安装并启用。
2. 先卸载旧包 `@enwork/form-assistant`（以及旧版 `@enwork/workbench-browser`，如有），再安装新包；按应用提示刷新/重启。
3. 在当前聊天右侧打开目标网页工作台，停留在列表页即可，不必先打开表单。
4. 直接发送附件和要求，例如：“根据这个文件新增一个招标意向，填好后让我核对。”Agent 自动发现右侧工作台，读取页面并点击真实的新增按钮，识别表单，再读取选项和填写。本插件本身不解析附件，也不向网站上传文件；资料由 Agent 现有文件能力读取。
5. 在原网页核对结果。Agent 在聊天里报告缺失资料、冲突及失败字段。已有内容不会静默覆盖；可在原网页自行调整，或按需使用 `forms` 诊断入口。保存和提交由你完成。

自动关联只覆盖当前聊天右侧的可见同源 iframe，依据 Harness 的 `data-sidebar-right-session` 归属边界隔离其他聊天。单个网页可直接操作；多个网页先由 Agent 根据目标名称选择，无法判断时才询问。聊天切换、页面隐藏或关闭会释放连接。应用内导航保留连接，但元素与字段需重新读取。自动发现不会自行点击或填写，操作仅在 Agent 调用工具时发生。不能自动打开尚未挂载的工作台插件，跨域或沙箱隔离页面仍需接入桥。

可打开插件的“在当前聊天右侧打开示例”，点击“关联示例网页”，发送合同指令，体验从菜单到表单的过程。示例不连接业务系统。

只安装此助手即可使用未改动的同源 iframe 工作台，不需要升级投标插件。助手仍兼容旧的主动接入事件，作为可选入口。

## 工作方式

- Client 自动观察应用文档和可访问子文档，结合可见性、焦点、iframe 加载/卸载、SPA 表单变化更新候选列表。
- 后台只注册当前聊天右侧页面的标题、路径和临时连接，发现时不发送字段值，也不点击或填写。
- `workbench_browser targets` 返回当前聊天的网页引用，模型不接收连接密钥。只有一个页面时工具可省略引用；多个目标不会默认猜选。主栏和其他聊天网页不会自动注册。
- Agent 使用当前配置的模型提取资料；没有另设 API Key 或演示规则。模型通道与数据设置沿用宿主。
- 原生控件写入后触发 input/change；组件选择框点击关联弹层中的真实选项；级联逐级展开并等待。页面导航后保留工作台连接，但元素和字段需要重新读取。对话变化或工作台关闭后连接失效；取消/超时不自动重放。
- 多个 iframe 不会在绑定后自动切换目标。无法读取的跨域页面不会被绕过限制或改写代理配置。

## 当前范围

支持可见的原生 input、textarea、select、checkbox、radio group 与原生多选；支持已适配的 Element Plus 选择框、地区级联、可编辑日期/年月，以及具备明确 ARIA 弹层关联的单选组合框。复用该结构的其他组件仍需实测。跳过密码、附件、隐藏项及普通只读输入。

级联传入完整、已知的选项标签路径，例如用户明确提供“浙江省 / 嘉兴市 / 海宁市”。Agent 将其编码为 `value: "[\"浙江省\",\"嘉兴市\",\"海宁市\"]"`。客户端逐级展开并等待，最后点击叶节点或严格模式单选按钮，核对完整路径回显。不存在、重名、禁用或加载失败时返回失败，不自动选近似地区。中间展开/选择可能触发页面联动，失败后的当前页面需重新核对。

原生省市区联动可按父到子顺序填写，并等待选项出现。组合多选只在明确识别为多选时支持添加，移除已有项暂需手动操作。年月工具值为 `YYYY-MM`，日期为 `YYYY-MM-DD`，客户端适配页面显示格式并触发组件提交事件。

虚拟化或远程搜索但尚未渲染的选项、复杂树、多选级联、富文本、只读日历、日期范围、明细行、多步骤仍需补适配。回读页面与组件选择状态不能替代后端最终保存/业务校验。

选择适配已使用真实网站公开前端和模拟账号验证了采购份额、年月以及省市区三级路径。该夹具使用合成数据字典，业务 API 全部本地拦截；不等同于真实业务账号保存验收。

自动发现覆盖普通 DOM 里的 iframe 和最多 4 层可访问嵌套页，最多 64 个候选。跨域、sandbox 隔离、浏览器标签页、原生 webview 和封闭 Shadow DOM 不属于直接访问范围。字段更改本身可能触发网站已有的自动保存。

**自动发现 iframe 与支持每种控件是两件事**：能找到工作台，不代表其中所有自定义表单都已兼容。真实登录页面仍需逐项验证。

## 开发

本仓库有独立源码、测试、构建及打包脚本，不依赖投标插件仓库。构建复用相邻 `../EnWork-Harness` 0.2.2-rc.1 的已安装依赖和构建工具；也可设置 `ENWORK_HARNESS_SOURCE` 指向匹配的 Harness 源码。脚本只在本仓库链接依赖及生成产物，不修改 Harness 源码或 profile。

```powershell
node scripts/build.mjs
node scripts/test.mjs
node scripts/pack.mjs
```

产物在 `dist/`，包含 tgz、完整性索引和带实际路径的安装说明。

目录：

```text
src/index.ts               Host 路由、模型工具与策略
src/broker.ts              临时任务、对话隔离、取消与超时
src/client/frames.ts       iframe 自动发现与生命周期观察
src/client/page.ts         网页连接、快照、菜单操作与应用内导航
src/client/automatic.ts    当前聊天右侧页面的无界面自动连接与任务执行
src/client/dom.ts          字段读取、控件写入与回读
src/client/controls.ts     原生/组件字段分组、标签与结构描述
src/client/widgets.ts      弹层选项、逐级等待与组件选择
src/client/Assistant.tsx   独立入口、选择、关联、冲突确认
tests/                    HTTP、工具、Client、DOM、发现测试
scripts/                  独立构建、测试和打包
```

模型未出现 `form_assist` 工具时，检查插件是否已启用并刷新/重启，以及当前 Agent 预设是否限制该工具。插件不会自动改变预设白名单。

## 可选主动接入

如果某个工作台希望保留自己的快捷按钮，可以继续发送以下事件；普通同源工作台不需要这段代码。

```ts
window.dispatchEvent(new CustomEvent('enwork:form-assist:activate', {
  detail: { frame: iframeElement, title: '工作台名称' },
}))
```

## 加载诊断

0.7.0 的 workbench_browser targets 返回 Host version 与每个目标的 clientVersion，正常均应为 0.7.0。目标路径应为实际应用路径，不应为 blank。缺少版本字段说明仍有旧版代码在运行，需要刷新或重启应用。加载中的空白 iframe 不注册为目标，真实页面加载完成后自动发现。

已使用真实无头 Edge 的本地模拟工作台验证：延迟设置 iframe src、读取页面、点击新增招标意向、SPA 路由切换、选表单并填写；未访问真实业务系统。

桌面应用使用 dsh-app://app 协议。0.7.0 同时支持该协议和 HTTP/HTTPS；自定义协议按 protocol/hostname/port 比较归属，不将 URL.origin 的 null 值当作同源凭据。已用本机已安装应用的 Electron 44.7.0 隔离运行时验证同协议下的发现、快照、点击新增、SPA 路由切换及填写，没有访问真实业务 API。

## 默认业务操作策略

Agent 自己读取附件并操作实际业务字段，默认不将工作转交网站自带的 AI 识别、智能提取或一键生成。网站的 AI 原文框不等于业务表单，粘贴原文或点击识别不算完成。用户明确要求使用网站 AI 时可以选择该路径；缺失资料、不能操作的控件和必须使用网站 AI 的步骤，应说明原因而不是自行改道。

策略同时写入系统提示词及两个工具的说明，以减少模型误用；这不是执行层对所有网站 AI 按钮的硬性封禁，也不是对任意模型行为的保证。原有 form_assist 工具名、HTTP 路径和事件保持兼容，仓库目录暂保留原位置。

## 操作锁定与接管

自动连接的目标 iframe 开始点击、导航、读取选择项或填写时显示顶部状态栏和浅色遮罩，阻止常规鼠标、滚动及键盘输入；聊天区和其他工作台不锁定。begin/finish 供 Agent 获取和结束连续操作，读取附件时无需加锁。成功结束后短暂显示核对提示并解锁；异常、断线、卸载也释放锁定。90 秒无新的操作会自动停止并转入人工接管状态，避免永久锁住。

点击“停止并接管”会取消后续异步操作，待当前执行退出后解锁；已完成的动作不回滚。接管后服务端拒绝后续网页工具调用，只有点击“允许 Agent 继续”才恢复；恢复会使旧元素和表单引用失效，要求重新读取。暂停的是网页操作，不是整个聊天模型的计算。原网页的自动刷新、联动或其他外部脚本仍可能改变字段，因此写入前还会检查字段值。此版本未对独立 dsh-browser 窗口加锁。
